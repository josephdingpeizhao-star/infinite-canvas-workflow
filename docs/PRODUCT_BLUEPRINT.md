# 产品形态蓝图 v1.0

> 2026-07-18 用户定稿

一句话定位：在已装画布的原生创作台上，把整条生产线装进一个可连线调用的
"制图机器"节点——图片是主角，流程隐身，美术总监说了算。
参照形态：画布软件自身的原生图片节点模式（图片即节点、连线即血缘、悬浮工具条）。

桌上六种东西：

1. 素材节点——白底图、风格参考图，拖入即真图，自由摆放；
2. 信息卡——产品信息（七项确认）与需求（几张主图/详情）两张卡片节点；
3. 工作流节点——"制图机器"，素材与卡片连线给它、按开始；内部工序永不展开；
4. 成图——机器每做好一张，画布实时多一张真图，与机器保持连线（血缘可见）；
5. 单图重做节点——不满意的图拖出来连给它、写一句要求（与生产同一连线语法）；
6. 已收货框——满意的图拖入；收满 14 张后出现“确认关账”按钮，用户确认后关账归档。

另有 AI 助手于对话框待命：说人话下指令、翻译异常、代看机器内部。

四条机器礼仪：

1. 进度条就是图片本身（流式上桌，无进度界面）；
2. 钱是唯一有资格拦路的（花真钱前弹确认卡：金额/张数/时长，不点不走）；
3. 返修与生产同一语法（都是"把东西连给节点"）；
4. 没有引擎室（工序/事件/状态由机器与助手消化，用户永不可见）。

两条边界原则：

1. 即兴与正规共存：画布原生单图加工全部保留，试验成果可反哺生产；
2. 正式交付物必须出自工作流（血统清白、来源可查；既有质检与账本继续生效）。

分期计划：M0 清桌子（本任务）→ M1 工作流节点 MVP（demo 演示模式，零成本）
→ M2 通真电（真图流式/费用确认卡接真闸门/QC 角标/收货框关账/单图重做链路）
→ M3 AI 助手到岗。

设计历史：5A 线性页面与 5A-R 卡片上画布两版形态均被用户
否决，其契约清单、缺口册、fork 实现路径、人话文案作为资产保留参考。
