# 项目部署说明

> 警示：密钥仅限公司内部私有仓库，禁止进入公开仓库、公开网盘、聊天记录或其他公开渠道。

## 新电脑安装

1. 前置准备：安装 Python、bun 和 Codex，并在 Codex 中完成登录。确认整个伞形项目文件夹已经复制到新电脑，主仓、`infinite-canvas`、`canvas-demo-workspace` 和 `杯类` 四个文件夹并排放置。
2. 双击本目录中的「安装到本机.bat」。脚本会把部署包内的两份凭据按字节复制到当前账户的个人目录；目标文件已存在时会先备份为 `.bak`，随后创建「无限画布工作台」和「停止画布工作台」两个桌面图标。
3. 安装完成后，首次打开画布时需要新建一个画布项目，并按页面提示连接本机 canvas-agent。之后可使用桌面图标启停工作台。

## 凭据迁移说明

- 旧电脑上由公司内部人员双击「导出凭据.bat」，把 `render-credentials.json` 与 `canvas-agent.json` 复制进 `deploy/credentials/`。脚本只做字节复制，不显示也不修改文件内容。
- `~/.codex/config.toml` 不随部署包迁移；新电脑应通过安装和登录 Codex 自行生成本机配置。
- 若安装失败，原目标文件仍可从同目录的 `.bak` 恢复；桌面图标可重新运行「安装到本机.bat」生成。
