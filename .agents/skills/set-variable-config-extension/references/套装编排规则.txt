【套装编排规则】

一、文件定位

本文件是套装产品生图的长期约束模块。在套装产品生图场景下，与《真实感约束》《道具生成规则模块》同属画面元素层与组合关系层约束，长期保留并调用。
单品产品生图时，本文件不启用。

本文件负责：
套装编排槽位体系；
套装整体机位说明；
套装组成与道具的双向声明；
套装件数与可分性在生图中的执行约束；
套装内主次关系的画面执行规则。

本文件不负责：
定义各单件产品身份，以各单件《产品身份档案》为准；
定义套装组合身份，以《套装产品身份档案》为准；
改变产品角度；
决定本张页面任务；
替代《真实感约束》《风格母版》或《本张变量配置》。

本文件的作用是：在《套装产品身份档案》已锁定套装组成的前提下，进一步约束套装在画面中如何编排、如何摆位、如何处理多件之间的空间关系，使套装图既符合产品组合事实，又像真实商业摄影。

二、套装的双轴角度体系

单品只有一个角度维度。套装的“角度”分裂为两个相互独立的维度，二者必须分别标注、分别约束：

维度一：整体机位
指相机相对整个套装的拍摄视角，沿用单品角度槽位 A、B、C、D 四类，但在套装场景下重新定义为纯机位描述，见第三节套装整体机位说明。

维度二：套装编排槽位
指套装中各组成单件之间的空间编排关系，与整体机位相互独立。
一张套装图必须同时具有一个整体机位槽位和一个套装编排槽位。

三、套装整体机位说明

单品角度槽位 A、B、C、D 在水壶类单品中通常会涉及壶口、壶身、壶底、壶柄或提梁、内壁、外壁等具体部位；套装场景下可能包含壶体、壶盖、出水口或直饮结构、滤网或壶垫、滤网、托盘、礼盒等多个单件，因此 A、B、C、D 只描述相机机位，不再绑定某一个单件部位：

整体机位 A：正面微俯视机位
相机略高于套装，接近正面。适合展示套装整体外观和正面图案的第一印象。

整体机位 B：45°斜侧机位
相机位于套装斜前方。适合展示套装的立体感、各单件的前后空间关系和生活化使用感。

整体机位 C：顶部俯视机位
相机位于套装正上方。适合展示套装的平面陈列关系、各单件的桌面布局和组合秩序。

整体机位 D：侧面低角度机位
相机接近套装高度。适合展示各单件的器型轮廓、高度关系和静物氛围。

各组成单件在某一整体机位下的具体角度，以该单件对应的白底图为准，不由整体机位反推。

四、套装编排槽位体系

套装编排槽位描述各单件之间的空间关系，固定为以下四类：

编排槽位一：并列陈列
各单件在同一水平面上并排摆放，彼此独立、不层叠。
适合展示套装件数、各单件完整外观和成套对比关系。
适合整体机位 A、B、C。

编排槽位二：主从层叠
配件件承托或叠放主体件，例如壶体置于滤网或壶垫或托盘上、壶盖盖在壶体上、滤网置于壶体旁、滤网或壶垫上或托盘上、套装内容物置于礼盒中。
适合展示固定搭配关系和套装的使用组合方式。
适合整体机位 A、B、D。

编排槽位三：阶梯纵深
各单件按前后纵深错位摆放，形成层次。
适合展示套装的立体感和生活化陈列。
适合整体机位 B、D。

编排槽位四：散开俯视
各单件在桌面上适度散开，从俯视呈现整体布局。
适合展示套装全部组成、件数和桌面陈列美感。
适合整体机位 C。

编排槽位的选择必须服从《套装产品身份档案》锁定的固有组合关系：
固定搭配的单件不得被编排成相互无关的散件；
成套不可拆的套装不得被编排成彼此孤立、毫无关联的状态。

五、套装组成与道具的双向声明

套装件多，AI 容易把配件件误当道具，或把道具误当套装组成。本文件要求双向声明：

1. 套装组成方向声明
《套装产品身份档案》套装组成清单中的全部单件，都是商品本体。
这些单件必须完整出现在画面中，件数正确，不得被弱化、虚化、移出焦点或移出画面。
即使某张图突出主体件，配件件也必须保持可见，只可弱化视觉权重，不可缺席。

2. 道具方向声明
不属于套装组成清单的物体，一律是道具，服从《道具生成规则模块》。
道具不得被强化、计数或摆放成疑似套装组成的样子，不得让用户误以为道具是套装的一部分。

3. 冲突裁定
当某个物体的身份在套装组成与道具之间含糊时，以《套装产品身份档案》套装组成清单为唯一依据：
在清单内即为商品，必须保留；不在清单内即为道具，服从道具规则。

六、套装件数与可分性的执行约束

1. 件数约束
画面中商品件数必须与《套装产品身份档案》锁定件数完全一致。
不得为构图丰富而增件，不得为画面简洁而减件。
重复调用同一编排槽位生成多张图时，件数始终不变。

2. 可分性约束
成套不可拆的套装，各单件应表现为成套关联的整体，可通过编排、摆位、距离体现关联。
可拆分单卖的套装，各单件可表现一定独立性，但仍须体现它们同属一个套装。
不得把可拆套装画成连体器物，不得把成套套装画成毫无关系的散件。

七、套装内主次关系的画面执行

1. 主体件应保持画面视觉重心，占比、清晰度和位置应优于配件件。
2. 配件件辅助说明套装价值，可弱化视觉权重，但不得被放大、前置或抢走视觉重心而压反主次。
3. 编排槽位选择不得改变主次：主从层叠中，承托的配件件不得喧宾夺主；阶梯纵深中，主体件不得被推到最弱的纵深位置。
4. 套装主图允许的“突出主体件”指调整视觉权重，不指删除或移出配件件。

八、套装编排与角度、真实感的优先级

套装编排出现冲突时，遵循以下顺序：
1. 套装件数、可分性、固定搭配、主次，以《套装产品身份档案》为准。
2. 整体机位与各单件角度，以《套装角度与编排入库表》、套装合影白底图和各单件白底图为准。
3. 编排槽位服务本张页面任务，但不得突破上述两项。
4. 真实摄影感，以《真实感约束》为准：各单件之间、单件与桌面之间必须有真实接触阴影、真实前后遮挡和合理空间关系，不得出现单件漂浮、穿模、件距粘连或层叠关系失真。
5. 风格与道具，以《风格母版》《道具生成规则模块》为准，不得牺牲上述各项。

套装外部的背景、桌面、布料、纸张、食物和外部道具可以保留非产品元素轻微真实瑕疵感，例如轻微真实世界痕迹、自然褶皱、轻微纹理、纸张轻微翘边、食物自然不规整和外部道具微小摆放偏差，以降低过度干净和过度合成感。
边界：《套装产品身份档案》套装组成清单中的全部单件都是商品本体，不得被做旧、加污渍、加划痕、弱化、虚化、移出画面或误当道具，不得改变任一单件的结构、比例、颜色、材质、纹理、图案和配件关系。清单外的物体才属于道具，并服从《道具生成规则模块》和《真实感约束》。

套装尺寸与外部参照关系
1. 套装真实尺寸与各单件真实尺寸以《套装产品身份档案》和各单件《产品身份档案》为准。
2. 套装合影白底图只锁定件数、相对比例和编排关系，不承担厘米级真实尺寸推断。
3. 外部道具只能表达已知尺寸关系，不能反推套装大小。
4. 当套装整体或关键单件尺寸无法确认时，不得使用手部、书本、托盘、滤网、手机等强比例参照元素暗示套装大小。
5. 不得为了画面美感把配件件放大成主体件，或把主体件缩小到不符合真实尺寸关系。

九、默认修正倾向

当不确定如何编排套装时，默认采用以下倾向：
1. 件数存疑时，以《套装产品身份档案》锁定件数为准，不增不减。
2. 编排存疑时，优先选择能完整展示全部单件的并列陈列或散开俯视。
3. 主次存疑时，强化主体件视觉重心，弱化但保留配件件。
4. 单件之间空间关系存疑时，强化接触阴影和前后遮挡，保证落地感。
5. 道具与套装组成存疑时，以套装组成清单为准，清单外一律按道具克制处理。
6. 套装本身已是多元素画面，道具一律从克制，服从《道具生成规则模块》中的【套装图道具专项规则】。
