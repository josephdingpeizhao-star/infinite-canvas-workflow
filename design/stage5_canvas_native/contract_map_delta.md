# 界面动作契约增量（阶段 5A-R）

本文件只记录“线性页面 → 画布原生节点卡片”带来的变化。旧 `design/stage5_ui_prototype/contract_map.md` 仍是49项业务动作的完整基线。

统计口径：旧49项中 **沿用33项、修订16项**；新增 **6项画布本地行为**。新增项全部是本地导航或画布操作，不新增后台能力。旧表的7项未接后台动作仍然受 NC-01～NC-04 约束。

## 新增画布本地行为

| 新ID | 行为 | 类型 | 边界 |
|---|---|---|---|
| D01 | 在六幕静态快照间导航 | 新增 | 仅设计稿相对链接，不对应产品后台 |
| D02 | 使用右下角缩放控件 | 新增 | 现有 Infinite Canvas 本地视口行为，不写业务数据 |
| D03 | 拖动画布或空白处平移视口 | 新增 | 现有画布本地行为，不改变仓库事实 |
| D04 | 拖动卡片并保存布局 | 新增 | 现有画布布局行为；只影响 `canvas_layout`，不影响执行依赖 |
| D05 | 展开/收起卡片详情 | 新增 | 本地展示状态；业务字段只有点击保存后才进入既有门禁 |
| D06 | 聚焦当前阶段或关联问题 | 新增 | 只改变视口位置与选中态，不改变节点状态 |

## 四项旧新契约提案保持不变

- NC-01 建批与资料接收：对应 C16～C18。
- NC-02 审批确认：对应 C31，并作为 C32 的服务端前置条件。
- NC-03 人工终审与关账：对应 C38、C39；QC原报告只读。
- NC-04 交付打包下载：对应 C45；只包含正式成图和唯一QC报告。

## 不得误读

- 画布上的按钮不等于后台已经支持。
- 5A-R 没有实现任何上述写入、执行、审批、终审或下载能力。
- `requested_outputs`、`notes`、`run:`、`retry:` 之外的写入，在新合同正式建立前仍不得上线。
