```text
五、生成变量配置阶段与最终出图阶段的区别

生成变量配置阶段：
目标是产出 6 套或指定数量的【单张变量配置】。
此时《本张变量配置》尚未存在，不能把它列为已存在源文件。

其中部分图片可被设计为手持场景，此类图片在设计时额外参照《手持产品场景基础模块》和《手持适配规则》，并在变量配置中写明手持交互声明；其余图片不引入手持模块。若用户明确指定本阶段或整批的手持图数量且作用范围清楚，变量配置阶段必须生成对应数量的手持配置，并在批次说明中写明用户要求数量、实际手持配置数量和未满足时的阻断原因；不得用默认规划、尺寸适配或页面任务判断静默减少该数量。

最终出图阶段：
目标是根据某一套已经生成好的【本张变量配置】生成图片。
此时可以正式调用《本张变量配置》。
最终出图时，本张变量配置只能在源文件约束下执行，不得推翻产品身份、角度入库表、真实感约束和风格母版。
若本张变量配置声明了手持交互，最终出图同时引入《手持产品场景基础模块》和《手持适配规则》；若未声明，则不引入这两份文件。
```

```text
- 辅助参考图名称或识别标记；
- 该图对应的单件产品；
- 本张是否调用；
- 调用目的：仅用于单件结构增强；
- 权限边界：本张产品角度仍以【绑定角度槽位】对应的白底产品图为唯一依据。

不得把单品版【辅助参考图调用】与套装版【辅助参考图调用】混合输出。
套装批次下，辅助参考图仍不得影响套装编排槽位、整体机位槽位、套装件数、主次关系、固定搭配、相对比例和任一单件角度。
```

```text
1. 启用数量（默认建议与用户明确数量）
单品批次的 6 套主图变量配置中，在用户没有明确指定手持数量时，默认目标为约 3 套启用手持、约 3 套不启用，使买家既能看到产品静物识别，也能看到使用感；该目标在尺寸中高且角度适配时应执行。用户明确指定手持数量且作用范围为主图时，必须生成对应数量的主图手持配置；用户明确指定整批手持数量但未分配主图 / 详情图范围时，必须先反馈确认，不得自行拆分。只有无用户明确数量要求且尺寸、角度、产品结构、页面任务或真实感存在明确冲突时，才可低于默认 3 套，并必须解释。最终启用手持的套数在无用户明确数量要求时先服从产品真实尺寸与尺寸置信度，再综合产品类型、角度槽位、页面任务和真实感判断：

若产品天然适合手持展示且角度槽位充足，也可以多于 3 套；

每一张变量配置提示词的“【手持交互声明】”项都必须加上：图片中出现的手必须真实自然，要有血色，并带有现实世界中的微瑕疵感，不得过度美化或生成得过于完美

启用：依据《手持产品场景基础模块》与《手持适配规则》填写第 3 条要求的全部内容。

3. 条件引用关系
某一套配置启用手持场景后，该套配置才引用《手持产品场景基础模块》与《手持适配规则》。《手持产品场景基础模块》提供手与产品交互的通用底层约束，包括产品身份锁定、接触关系、遮挡控制、角度服从、静态握持与动态拿起的边界；《手持适配规则》按产品类型给出具体的合理持握位置、禁止持握位置、允许遮挡区、必须保留可见区、是否离桌、单双手裁定。不启用手持场景的配置不引用这两份文件，其【手持交互声明】栏写”本张图不启用手持场景”。

4. 套装批次的差异
本节”默认建议约 3 套”的规则仅适用于单品批次。套装批次不适用本节数量目标，套装手持规则以《套装产品工作流补充规则》第七节和《套装变量配置补充模块》【手持交互声明】条目为准。

3. 与角度规则的兼容
手持场景必须服从既有角度槽位体系。手部动作适配本张【绑定角度槽位】对应的白底产品图角度，不得为某种握姿要求产品旋转、翻转、改变朝向、改变壶口可见程度、壶身外壁透视或壶底与底足可见关系。若某个握姿必须依赖另一个角度才能成立，应将该套配置改绑更合适的槽位，或改用其他握法，而不是旋转产品。

4. 与产品主体的兼容
手是画面互动元素，不是画面主体，也不是道具。手不得遮挡产品核心识别区域，包括正面主体图案、壶口轮廓、壶口边缘厚度、壶身器型、壶内主要可见区域与配件连接关系；手不得大面积包裹产品，不得抢夺视觉中心。手持主图的视觉中心仍是产品，手只作为辅助交互元素存在。手不计入《道具生成规则模块》的道具数量，【手持交互声明】栏与【道具生成】栏互相独立。

5. 与主图任务的兼容
手持场景适合承担表现使用感、生活方式、真人互动第一印象类的主图任务，不适合承担纯结构识别、纯材质展示类任务。手持子场景在静态握持与动态拿起之间选择：静态握持表现产品被稳定握住、托住或扶住；动态拿起表现产品刚被拿起、轻微离桌的瞬间。主图不追求大幅度动作，动态拿起的离桌幅度应小而明确。
```

```text
8. 详情图（材质说明、结构说明、特写）：0 至 3 个道具，若道具会干扰结构或材质识别，应减少或不使用。

11. 道具上限一般不超过 5 个；不得为达到某个数量而强行添加无关道具。常规摄影类适用此上限；若本张按“丰富生活场景”或“风格复现型”密度等级执行，非产品元素可分别达到 6 个、7 个，但须分布于前景、中景、背景层次，不在主体周围堆叠。
11·一. 道具密度等级（与正文三·一一致，供《风格母版》《本张变量配置》标注后调用）：极简 0–2 个道具、克制 1–3 个道具、常规 2–4 个道具、丰富生活场景 3–6 个非产品元素、风格复现型 4–7 个非产品元素。本张如已标注密度等级，优先服从该等级再在范围内微调；标注为“丰富生活场景”“风格复现型”时不得自动减为 1–3 个，须保留下限。当《风格母版》非纯色、非极简背景时，本张至少说明前景、中景、背景中的两层，风格复现型须说明三层，背景不得无故退化为纯白、纯灰或仅轻微渐变。以上调整不改变“道具不得遮挡主体、不得抢视觉中心、不得改变产品身份与角度、不得破坏真实感”的底线。
```
