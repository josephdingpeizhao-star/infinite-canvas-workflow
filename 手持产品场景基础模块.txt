【手持产品场景基础模块】

一、文件定位

本文件是 AI 电商图片生成工作流中的长期固定源文件，用于约束所有“手部握持产品”和“手将产品拿起、离开桌面”场景图中，手与产品之间的交互关系。

本文件只负责手与产品的交互边界，不负责其他职责：
1. 不负责定义产品身份。产品的结构、比例、颜色、材质、纹理、图案和配件关系，以《产品身份档案》为准。
2. 不负责规定产品角度。产品的朝向、俯仰关系、壶口可见程度、壶身外壁与壶底或底足透视关系、壶体与配件的空间关系，以《角度入库表》和本张绑定槽位对应的白底产品图为准。
3. 不负责决定页面任务。本张图要承担什么主图或详情图任务，以《主图单张变量配置》或《详情图单张变量配置》为准。
4. 不负责定义画面风格。背景、色调、光线倾向、留白、文字气质和道具密度，以《风格母版》为准。
5. 不重复《真实感约束》中已有的手部真实性规则。手指数量、长度、关节、弯曲方向、皮肤质感、是否畸形等手部本体真实性问题，以《真实感约束》第九节为准。本文件只负责手“如何与产品发生关系”，不重新定义手本身。
6. 不替代《道具生成规则模块》和《本张变量配置》。

本文件的作用是：在《产品身份档案》《角度入库表》《风格母版》《真实感约束》已经确定的前提下，当一张图需要表现手持产品场景时，进一步约束手与产品的接触、遮挡、受力、动态状态和光影衔接，使产品在加入手部交互后仍被严格锁定为原产品，而不是被模型重新设计。

二、适用范围与启用条件

本文件适用于以下两类场景图：
1. 静态握持图：手握住、托住或扶住产品，产品仍保持基本静置状态。
2. 动态拿起图：手将产品拿起，产品离开桌面，画面表现“动作正在发生”。

本文件不默认启用。只有当《本张变量配置》明确声明本图使用手持场景时，本文件才参与约束；当用户明确要求启用手持场景或明确指定手持图数量时，变量配置阶段必须把对应数量的图片声明为手持场景，除非先输出阻断反馈或要求补充信息。普通静物摆放图不得因为本文件存在而强行加入手部。

套装批次适用说明：
套装批次下，本文件仍仅在《本张变量配置》的【手持交互声明】明确启用时参与。套装批次启用手持时，手持交互只作用于被持握的某一个主体单件；其余套装组成单件必须作为静物陈列保持可见、件数完整、编排关系不变。

三、本文件在工作流中的位置与优先级

本文件不改变《工作流总控规则》已确定的文件优先级。手持交互属于“画面互动元素”层级，其位置低于产品身份、产品角度和页面任务，与真实摄影感、道具处于同一约束层级。

手持场景图的执行优先级如下：
1. 产品身份准确。以《产品身份档案》为准。
2. 产品角度准确。以《角度入库表》和本张绑定槽位白底图为准。
3. 页面任务与产品可识别度。以本张主图或详情图变量配置为准。
4. 手与产品的交互真实性。以本文件为准。
5. 风格一致性。以《风格母版》为准。
6. 道具与氛围。以《道具生成规则模块》为准。

核心铁律：产品身份锁定高于手部动作表现。手只是辅助交互元素，不能反过来主导产品结构。当手部动作、动态效果或持握姿态与产品身份或产品角度发生冲突时，一律牺牲手部表现，保留产品。

四、调用接口

当《本张变量配置》使用手持场景时，应包含一段“手持交互”声明，声明项如下：
1. 子场景类型：静态握持 或 动态拿起。
2. 单手或双手：默认由《手持适配规则》根据产品类型判定，本张变量配置可在其允许范围内指定。
3. 持握或托举的部位方向：例如握住壶柄或提梁、扶住壶身外壁、托住壶底或底足、双手捧住壶身、托住滤网或壶垫或托盘边缘、轻扶壶口边缘下方。具体合理性由《手持适配规则》裁定。
4. 是否离桌、离桌幅度（仅动态拿起场景需要）。
5. 产品尺寸摘要与尺寸置信度：必须写明被持握产品的真实尺寸摘要和尺寸置信度。
6. 动态手持样式参考图调用：仅当子场景类型为“动态拿起”，且《本张变量配置》明确提供手持样式参考图时填写。需写明参考图名称或识别标记、是否调用、调用目的、允许读取内容、禁止读取内容和冲突降级规则。

本文件只定义这一调用接口。产品身份、产品角度、页面任务、镜头距离、构图方式、展示重点仍由对应文件和《本张变量配置》原有栏目负责，本文件不重复，也不改写。

手持尺寸适配规则
1. 启用手持场景前，必须读取《产品身份档案》的【产品真实尺寸】；套装批次读取被持握主体单件的【产品真实尺寸】。
2. 尺寸置信度为中或高时，手部按真实成人手尺度与产品形成符合真实尺寸的比例关系。
3. 尺寸置信度为低或无法确认且用户没有明确手持要求时，默认不启用手持场景，改用普通静物方案；若用户明确要求手持，不得静默改用普通静物方案，必须输出阻断反馈或要求补充真实尺寸、可用角度或安全持握信息。
4. 不得为了构图缩放产品或手部；产品在手中显得过大或过小均视为尺寸比例错误。
5. 如果产品实际尺寸不适合单手握持，不得强行生成单手握持；无用户明确手持要求时可改用双手托持、轻扶、静物陈列或取消手持；用户明确要求手持时，应优先改为可可靠执行的双手托持或轻扶，若仍不可行则阻断反馈，不得静默取消手持。
6. 产品占画面比例只代表镜头距离，不代表产品在手中的真实尺寸改变。

五、产品身份锁定优先（手持场景核心规则）

加入手部交互时，模型不只是添加一只手，还会重新计算产品与手的接触关系、遮挡关系、受力方向、透视、阴影和动作状态。在这个过程中，产品的壶身比例、壶口形状、壶口边缘厚度、壶壁弧度、壶底或底足、壶柄或提梁方向、外壁图案位置、壶体与配件的空间关系和材质质感都有被顺带改动的风险。本文件要求：

套装批次下，“产品身份”指《套装产品身份档案》加各组成单件《产品身份档案》；手持交互不得覆盖套装件数、各单件身份、主次关系、相对比例、固定搭配和编排关系。

1. 产品是刚性容器或稳定商品（陶瓷、玻璃、金属、塑料等材质以《产品身份档案》为准），手与产品接触只产生遮挡和受力痕迹，不产生产品形变。手不得挤压、重塑、压扁或改变产品主体。
2. 产品结构、比例、颜色、材质、纹理、图案、壶口、壶口边缘、壶身、壶壁、壶底或底足、壶柄/提梁/壶盖/出水口/滤网/勺/托盘等配件关系，必须严格沿用参考图与《产品身份档案》。手部交互不构成重新设计产品的理由。
3. 不得借“接触关系”“受力关系”为名改变壶口形状、壶口边缘厚度、壶壁弧度、壶身比例、壶底或底足结构、壶柄或提梁方向、图案位置。
4. 手与产品是两个独立物体。手可以遮挡产品的一部分，但被遮挡的部分不等于不存在，更不等于可以被改形。
5. 当模型在手部动作与产品身份之间难以兼顾时，默认降低或简化手部动作，优先保住产品身份。

六、接触关系通用规则

1. 所有持握点、支撑点、托举点都必须有真实受力逻辑，符合《真实感约束》第八节的物理接触要求。
2. 手与产品的接触必须真实贴合，不得出现手悬在产品旁边却没有真实作用、或手指穿入产品内部的情况。
3. 手指与产品接触处应有自然的轻微受力痕迹和接触阴影，但不得因受力而使产品变形。
4. 产品被握持时仍必须有明确、可信的支撑逻辑：静态握持时产品重量由手和（如有）桌面共同承担；动态拿起时产品重量完全由手承担。
5. 手部本身的比例、关节和姿态真实性，以《真实感约束》为准，本文件不重复。

七、遮挡控制通用规则

1. 手可以遮挡产品的次要区域，但不得遮挡决定“这是哪个产品”的核心识别区域。
2. 通用必须保留可见的区域包括：正面主体图案、壶口轮廓、壶口边缘厚度、壶身器型、壶内主要可见区域、壶柄或提梁连接关系、壶盖/出水口/滤网/密封圈等配件空间关系、配件连接点，以及《产品身份档案》中列为不可改变的关键特征。具体到某一产品类型，允许遮挡区域和必须保留可见区域以《手持适配规则》为准。
3. 手的遮挡范围应尽量小且自然，不得为了表现“握得稳”而用手大面积包裹产品、盖住主体。
4. 如果在当前角度下，合理持握位置必然遮挡关键识别区域，应优先调整持握方式或改用不依赖手持的方案，而不是牺牲产品识别。
5. 手不得遮挡到让用户无法判断这是哪个产品的程度。

八、角度服从规则

套装批次下，“角度依据”指《套装角度与编排入库表》、本张绑定套装合影白底图和被持握单件对应白底图。

1. 手持模块必须服从现有的角度槽位体系。手部动作应主动适配本张绑定槽位对应的白底产品图角度，而不是要求产品为了配合手部动作而改变角度。
2. 产品在新画面中的朝向、俯仰关系、壶口可见程度、壶身外壁与壶底或底足透视关系和壶体与配件的空间关系，仍以本张绑定槽位对应的白底产品图为唯一依据。
3. 手持动作只能在当前角度前提下建立合理的接触关系，不得反过来重塑产品视角。
4. 如果某个持握姿态必须依赖另一个产品角度才能成立，应将该图改绑到更合适的角度槽位，或调整持握方式，而不是为了手部动作旋转、翻转产品或改变壶口可见程度、壶身外壁与壶底或底足透视关系。

九、静态握持子场景边界

静态握持相对更容易控制，重点解决持握位置、接触自然、遮挡控制和光影一致性。

1. 静态握持表现产品被握住、托住或扶住，产品未明显离开原有静置状态，或仅有极轻微的位置变化。
2. 持握位置必须符合《手持适配规则》中对应产品类型的合理持握判断。
3. 产品与桌面、滤网或壶垫、托盘、壶盖、出水口或直饮结构、滤网或其他套装配件的接触关系基本保持，接触阴影仍然存在并符合《真实感约束》。
4. 手部光影必须与画面整体光线方向一致，不得让手部出现与产品、桌面不同方向的光源。
5. 静态握持不得借“扶”“托”的动作改变产品角度或产品结构。

十、动态拿起子场景边界

动态拿起难度高于静态握持。它不仅要有手和产品，还要表现“动作正在发生”，因此会新增多个变量，必须逐项控制。

1. 离桌状态：需明确产品是否已经离开桌面。一旦表现离桌，产品底部就不应再与桌面接触。
2. 离桌高度：离桌高度必须合理。电商图不追求大幅度动作，建议表现“刚刚拿起、轻微离桌”的瞬间，离桌幅度小而明确。
3. 受力方向：手指受力方向必须真实，符合“正在把产品提起”的动作逻辑。
4. 接触阴影：产品离桌后，壶底或底足与桌面的接触阴影应相应消失或转变为产品下方桌面上的投影，不得保留贴地的接触阴影，否则会出现“既离桌又贴地”的矛盾。
5. 手腕与前臂：手腕和前臂姿势必须自然，符合真实拿取动作，不得僵硬或畸形（手部本体真实性以《真实感约束》为准）。
6. 内容物状态：如壶内有可见咖啡、茶、水、牛奶、果汁、冰饮、奶泡或其他液体/内容物，应保持自然稳定。除非《本张变量配置》明确表现饮用、倒入、搅拌、递送或轻微倾斜展示动作，否则不得出现夸张倾斜、飞溅或溢出。
7. 配件去留：如为壶具套装、带盖水壶、带直饮结构水壶、壶盖滤网组合、壶体与滤网或壶垫/托盘组合等组合产品，被拿起部分离桌后，留在桌面的配件去留以《手持适配规则》和本张页面任务为准，配件不得凭空漂浮，也不得无故消失。
8. 动态拿起的目标是传达使用感，同时保证产品仍清晰可辨。当动作幅度与产品清晰展示发生冲突时，缩小动作幅度，保住产品清晰度。

十·一、动态手持样式参考图调用规则

* 动态手持样式参考图是可选输入，不默认启用。
* 只有当本张变量配置启用“动态拿起”并明确写明调用参考图时，该图才参与本张生成。
* 允许读取：手部入画方向、手与产品的大致相对位置、握持 / 托举动作倾向、刚刚拿起的轻微离桌幅度、画面裁切方式、手腕与前臂的自然姿态、手与产品之间的真实接触阴影和光影衔接方式。
* 禁止读取：参考图中的产品身份、产品角度、产品颜色、产品尺寸、品牌、文案、人物身份、皮肤特征、服饰、饰品、背景专属物、不可复用构图细节。
* 参考图不得要求当前产品改变结构、比例、颜色、材质、纹理、图案、配件关系、真实尺寸或绑定白底图角度。
* 如果参考图手势与当前产品类型、真实尺寸、绑定角度、合理持握位置、遮挡控制或页面任务冲突，必须降低参考图调用权重，改用《手持适配规则》中的安全持握方式；仍无法兼顾时取消参考图调用或取消手持。
* 动态拿起仍以“刚刚拿起、轻微离桌”为优先，不追求大幅动作。
* 手部样式不得喧宾夺主，产品仍是画面主体。

十一、光影与真实感衔接

1. 手部、产品、桌面和道具必须处于同一套光线逻辑下，主光方向一致。
2. 手与产品之间、产品与桌面之间的接触阴影和投影必须符合《真实感约束》，不得出现漂浮感、贴片感或阴影方向混乱。
3. 离桌状态下的阴影变化见第十节第 4 条。
4. 手部作为非产品互动元素，可以保留自然皮肤纹理、轻微肤色差异、真实关节阴影和真实接触压感，避免过度磨皮、假肢感和过度棚拍感。
5. 手部真实感不得导致产品被改形、改色、加污渍、加划痕、改变产品结构、改变产品比例、改变产品材质、改变产品纹理、改变产品图案或改变配件关系。手部仍不得遮挡产品核心识别区域。
6. 本文件不重复《真实感约束》的材质、景深、AI 痕迹控制等规则，相关要求一律以《真实感约束》为准。

十二、手与道具、风格、页面任务的关系

1. 手是互动元素，不是道具。手的数量、位置不计入《道具生成规则模块》的道具数量，但手同样不得喧宾夺主、不得抢夺视觉中心、不得让画面变成“手的展示图”。
2. 画面中同时存在手和道具时，道具仍服从《道具生成规则模块》，并应为手与产品的交互留出空间，不得与手部争抢主体周围区域。
3. 手持交互不得改变本张页面任务。如果某张图的页面任务是产品结构或材质识别，而手部交互会干扰识别，应弱化或取消手部。
4. 手部表现不得优先于产品清晰展示。动态效果、使用氛围都属于产品清晰展示之后的次级目标。

十三、默认修正倾向

当模型不确定如何处理手持场景时，默认采用以下倾向：
1. 动作幅度不确定时，取更小的幅度。
2. 单手与双手不确定时，按《手持适配规则》对应产品类型的默认值，通常默认单手。
3. 是否离桌不确定时，默认不离桌或仅轻微离桌。
4. 持握位置不确定时，优先选择壶柄/提梁/把手、壶身外壁非核心识别区域、壶底或底足、壶身下半部等真实可支撑区域；如原图水壶类产品本身带壶柄或提梁或把手，则以《产品身份档案》为准；若原图没有，不得添加。
5. 手部遮挡与产品识别冲突时，优先保住产品识别，缩小手部遮挡。
6. 手部动作与产品身份或角度冲突时，优先保住产品身份和角度。
7. 当手部交互明显削弱产品清晰度且无法兼顾时，无用户明确手持要求时可取消手部，改用普通静物方案；用户明确要求手持时必须先尝试缩小遮挡、调整持握位置或更换可承接角度，仍不可行时输出阻断反馈。
8. 尺寸不确定且用户没有明确手持要求时，默认取消手持，而不是默认单手或轻微离桌；用户明确要求手持时，不得以尺寸不确定为由静默取消，必须要求补充尺寸或输出无法可靠生成的阻断原因。

十四、禁止事项

1. 不得将手持场景写成或生成成泛泛的“加一只手拿着产品”，必须落实到接触、遮挡、受力和角度的具体约束。
2. 不得让手部动作覆盖或推翻产品身份规则。
3. 不得让动态效果、使用氛围优先于产品清晰展示。
4. 不得借手部接触、受力为名改变产品结构、比例、颜色、材质、纹理、图案及配件关系。
5. 不得为了配合手部动作改变产品角度、朝向、俯仰关系、壶口可见程度、壶身外壁透视或壶底与底足可见关系。
6. 不得用手大面积包裹、盖住产品主体或核心识别区域。
7. 不得出现“产品已离桌但仍保留贴地接触阴影”等动态矛盾。
8. 不得为了手部自然皮肤纹理、轻微肤色差异、真实关节阴影或真实接触压感，让产品本身出现污渍、划痕、裂纹、破损、做旧、掉色、釉面瑕疵或原图不存在的细节。
9. 不得与《产品身份档案》《角度入库表》《真实感约束》《道具生成规则模块》《电商图片通用质检清单》《本张变量配置》重复定义同一职责或写入与之冲突的规则。
10. 套装批次不得表现一只手或双手同时持握整个套装；不得因手持导致套装缺件、主次压反、相对比例改变或编排关系改变。
11. 不得在尺寸缺失时生成手持图。
12. 不得把产品缩小成掌心小物。
13. 不得把产品放大到超过成人手自然持握范围。
14. 不得为了手持效果改变产品真实尺寸。

十五、与质检的衔接

手持场景图的质检仍使用《电商图片通用质检清单》，不另设质检标准。手持场景中常见的问题按现有清单归类返修：
1. 产品被手挤压、改形、改色、图案错位——归为产品身份问题，返回《产品身份档案》或最终出图提示词修正。
2. 产品为配合手部动作改变了角度——归为产品角度问题，返回《角度入库表》或《本张变量配置》修正。
3. 手部畸形、接触失真、漂浮、阴影不贴地、离桌矛盾——归为真实感问题，返回《真实感约束》修正。
4. 手部遮挡过多、抢夺视觉中心——归为构图问题或道具问题，返回《本张变量配置》修正其手持交互声明。
5. 手持交互与页面任务不匹配——归为页面任务问题，返回对应主图或详情图变量配置修正。
6. 手持比例错误，即产品与手的大小关系不符合尺寸字段——归为尺寸比例问题，返回《产品身份档案》的尺寸字段或《本张变量配置》的手持交互声明修正。
质检阶段不得临时新增与本文件或其他源文件冲突的规则。
