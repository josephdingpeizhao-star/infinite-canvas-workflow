# 项目部署说明（GitHub 协作版）

> 警示：密钥仅限公司内部私有仓库，禁止进入公开网盘、聊天记录或其他公开渠道。

本项目由两个 GitHub 仓库组成：

- **infinite-canvas-workflow**（大脑：规则、后端程序、凭据）
- **infinite-canvas**（操作画面：画布界面，用 `workflow-editor` 分支）

装好之后的日常协作方式：管理员改动并推送 → 同事拉取更新 → 重启工作台即可用上，见第二部分。

---

## 第一部分：新电脑第一次安装（只做一次）

### 第 1 步：装四个免费软件

1. **Python 3.12** —— 官网 python.org 下载安装。**安装第一屏务必勾选 "Add python.exe to PATH"**，其余一路下一步。
2. **bun** —— 官网 bun.sh，按首页给出的 Windows 安装方式操作（复制它给的那行命令，粘贴进系统自带的 PowerShell，回车）。
3. **Codex 命令行工具** —— 按官方说明安装，装好后登录**自己的** Codex 账号（工作流的文字步骤用它跑，零费用）。不清楚怎么装就问管理员。
4. **GitHub Desktop** —— 官网 desktop.github.com 下载安装，用自己的 GitHub 账号登录。

### 第 2 步：让管理员开权限

管理员在 GitHub 网页上把你的账号加为两个仓库的协作者。你的邮箱会收到两封邀请邮件，都点接受。

### 第 3 步：取回项目

1. 在桌面（或任意喜欢的位置）新建一个文件夹，命名为：**无限画布工作流**
2. 打开 GitHub Desktop → File → Clone repository → 选 **infinite-canvas-workflow** → Local path 选到刚建的「无限画布工作流」文件夹里，并把路径末尾的文件夹名改成 **无限画布工作流** → 点 Clone
3. 再来一次：File → Clone repository → 选 **infinite-canvas** → Local path 同样选到「无限画布工作流」文件夹里（文件夹名保持 infinite-canvas 不用改）→ 点 Clone
4. **切分支（重要）**：在 GitHub Desktop 顶部中间点 Current branch → 选择 **workflow-editor**。不切的话画面是旧版。
5. 回到「无限画布工作流」文件夹，再新建一个空文件夹，命名为：**杯类**（生产的图片批次会存在这里）

完成后「无限画布工作流」文件夹里应有四样东西并排：`无限画布工作流`、`infinite-canvas`、`杯类`，（`canvas-demo-workspace` 演示数据可有可无）。

### 第 4 步：装依赖（唯一要打命令的一步）

1. GitHub Desktop 左上角确认当前仓库是 **infinite-canvas** → 菜单 Repository → **Open in PowerShell**（或 Command Prompt）
2. 在弹出的黑窗口里输入 `cd web` 回车，再输入 `bun install` 回车，等它跑完（会下载约 900 MB，几分钟）
3. 接着输入 `cd ..\canvas-agent` 回车，再输入 `bun install` 回车，跑完关掉窗口

### 第 5 步：装凭据和桌面图标

打开 `无限画布工作流\无限画布工作流\deploy`，双击 **安装到本机.bat**。它会把两份凭据复制进你的个人目录（原文件存在时先备份为 `.bak`），并在桌面创建「无限画布工作台」「停止画布工作台」两个图标。

### 第 6 步：第一次启动

1. 双击桌面「无限画布工作台」，浏览器会自动打开画布页
2. 新建一个画布项目，按页面提示连接本机 canvas-agent
3. 首次运行工作流若弹出 Codex 信任确认，点同意（零费用）

---

## 第二部分：日常拿更新

管理员说"有更新"后，照做这四步（不用管这次改的是什么）：

1. 打开 GitHub Desktop，左上角切到 **infinite-canvas-workflow**，点 Fetch origin；出现 Pull 按钮就点 Pull
2. 左上角切到 **infinite-canvas**，同样 Fetch → Pull
3. 双击「停止画布工作台」，再双击「无限画布工作台」
4. 在画布页按 **Ctrl+F5** 强制刷新一次

若管理员特别说明"这次更新了凭据"，多做一步：重新双击 `deploy\安装到本机.bat`。

---

## 凭据说明

- 管理员侧：双击「导出凭据.bat」把 `render-credentials.json` 与 `canvas-agent.json` 复制进 `deploy/credentials/`（只做字节复制，不显示不修改内容），提交推送后同事即可拉到。
- 出图走这份凭据对应的服务商账户计费。
- `~/.codex/config.toml` 不随项目走；每台电脑各自安装并登录 Codex。
- 安装失败时，原凭据可从个人目录同名 `.bak` 文件恢复；桌面图标可单独用 `launcher\创建桌面入口.bat` 重建（双击只建启动图标，带「维护」参数运行则同时建停止图标）。

## 备用方案：整文件夹拷贝

不走 GitHub 也可以把整个「无限画布工作流」文件夹（含全部四个子文件夹）直接复制到新电脑，再从上面第 1 步装软件、第 5 步装凭据接着做。此方式拿不到后续更新，仅适合一次性搬家。
