```text
【工作流总控规则】

【当前生产架构覆盖规则｜2026-06-11】

本节优先级高于本文中所有“ChatGPT 最终出图”“复制到 ChatGPT 聊天窗口生成图片”等旧版表述。

1. ChatGPT 只用于流程讨论、业务规则修订、产品身份档案草稿审核、风格母版草稿审核、模糊视觉判断、低置信条目人工复核。

5. 所有批次输出必须保存为 artifacts/<product_id>/ 下的结构化产物；每个工程或生产阶段都必须写入 JSON 与 Markdown 报告，并由报告门禁决定是否继续。
6. 当前架构机器可读来源为 manifests/workflow_architecture.json；旧版 ChatGPT 直出措辞仅保留为历史上下文或人工审核辅助，不作为生产执行路径。
```

```text
使用《电商图片通用质检清单》。

尺寸标注图如出现尺寸数值编造、单位错误、标注线与产品边界不贴合、标注当前角度不可见或未确认的尺寸、文字乱码、信息图过度复杂、遮挡产品主体等问题，归入“尺寸标注问题”或“文字 / 构图 / 尺寸比例问题”，返回《产品身份档案》的尺寸字段、《本张变量配置》的【尺寸标注信息】和【尺寸标注图规则】修正；不要求补尺寸校准图，但缺失尺寸不得被模型自行估算。
详情页模块链路问题，返回《淘宝天猫详情页链路与平台规范模块》和《详情图单张变量配置提示词生成》修正。
商品信息一致性问题，返回《商品信息补充清单》或删除无法核验内容。
平台素材规格问题，返回最终导出 / 后处理流程修正，不得改变产品身份或角度。
虚假背书或售后承诺问题，删除该背书、承诺或相关画面文字；本工作流不要求通过《商品信息补充清单》补充证书、报告、评价、售后、退换或 FAQ。
“资料缺失 / 未提供”被渲染到画面中的问题，返回《详情图单张变量配置提示词生成》的【中文营销文案】和【文字渲染要求】删除流程说明。
套装批次质检在通用质检基础上追加“套装组成问题”归类和套装专项质检。
```

## workflow_variable_vs_final

- source: `工作流总控规则.txt:382-394`
- audit_ref: `reports/runtime_rule_index.json#/slices/workflow_variable_vs_final`

```text
五、生成变量配置阶段与最终出图阶段的区别

生成变量配置阶段：
目标是产出 6 套或指定数量的【单张变量配置】。
此时《本张变量配置》尚未存在，不能把它列为已存在源文件。
本阶段要根据《产品身份档案》《风格母版》《角度入库表》《真实感约束》《道具生成规则模块》《电商图片通用质检清单》，以及详情页的《淘宝天猫详情页链路与平台规范模块》和四项《商品信息补充清单》，来设计每张图的页面任务、角度槽位、构图、镜头距离、产品占比、文字和道具。
其中部分图片可被设计为手持场景，此类图片在设计时额外参照《手持产品场景基础模块》和《手持适配规则》，并在变量配置中写明手持交互声明；其余图片不引入手持模块。若用户明确指定本阶段或整批的手持图数量且作用范围清楚，变量配置阶段必须生成对应数量的手持配置，并在批次说明中写明用户要求数量、实际手持配置数量和未满足时的阻断原因；不得用默认规划、尺寸适配或页面任务判断静默减少该数量。

最终出图阶段：
目标是根据某一套已经生成好的【本张变量配置】生成图片。
此时可以正式调用《本张变量配置》。
最终出图时，本张变量配置只能在源文件约束下执行，不得推翻产品身份、角度入库表、真实感约束和风格母版。
若本张变量配置声明了手持交互，最终出图同时引入《手持产品场景基础模块》和《手持适配规则》；若未声明，则不引入这两份文件。
```

## realism_runtime_summary_source

- source: `真实感约束.txt:244-286`
- audit_ref: `reports/runtime_rule_index.json#/slices/realism_runtime_summary_source`

```text
十五、精简约束摘要（可选，用于 ChatGPT 最终出图提示词）

本节是上文规则的精简执行版本，用于在 ChatGPT 聊天窗口生成图片时压缩上下文使用；若完整源文件已作为上下文提供，应以完整正文为准。本节不替代上文完整规则。

【真实感约束精简摘要】

产品身份与角度锁定：
1. 产品结构、比例、颜色、材质、纹理、图案、配件关系不得改变，以《产品身份档案》为准。
2. 产品角度必须服从本张绑定白底角度图，不得因氛围、风格、道具或动作改变朝向、俯仰关系、壶口可见程度、壶身外壁透视、壶底或底足可见关系和壶体与配件的空间关系。
2·一. 产品颜色以本张绑定白底产品图为唯一颜色参照；套装中各组成单件颜色分别以对应单件白底图为唯一颜色参照。真实光影只允许造成局部合理明暗，不得造成商品本体整体偏色、风格滤镜染色、冷暖色漂移或饱和度漂移。辅助参考图、多角度参考图、风格参考图和套装合影白底图只读结构与构图，不读其色相、白平衡、曝光、饱和度和环境色，不作商品本体颜色依据。

光影与接触：
3. 主光方向必须明确且唯一，整套画面共用同一套光线逻辑；产品、道具、桌面、背景的高光和阴影方向必须一致。
4. 产品与桌面、产品与滤网或壶垫、托盘、壶盖、出水口或直饮结构、滤网、其他套装单件或道具之间必须有真实接触阴影；不得出现漂浮感、悬空感、贴片感或阴影方向混乱。
5. 阴影边缘软硬必须符合光源类型，柔光下边缘柔，硬光下边缘锐，不得全部一刀切柔化。

材质表现：
6. 水壶类产品必须有真实釉面反光、自然颗粒和烧制肌理，不得塑料化、蜡感化、3D 渲染化；透明材质水壶必须有真实透明度、折射和边缘高光。
7. 金属水壶或保温水壶高光锐利，木材有自然纹理和粗糙度差异，布料有自然褶皱与厚薄，液体有真实液面反光。
8. 不同材质必须可区分，不得被统一为同一种柔软顺滑的 AI 质感。
9. 边缘厚薄、连接转折、底部支撑必须真实，不得边缘融化、轮廓发软、局部塌陷。

景深与镜头：
10. 景深符合真实镜头规律，焦点区域清晰，非焦点区域自然过渡虚化，不得出现"主体清晰、其他全部一键虚化"的假镜头效果。
11. 透视真实，前后景空间关系合理；镜头距离不得用来制造绑定角度中不存在的结构信息。

手部与互动元素：
12. 手部本体真实性（手指数量、长度、关节、弯曲方向、皮肤质感）必须正常，不得畸形或塑料化。
13. 若画面中出现手，手与产品的接触必须真实贴合、有受力痕迹和接触阴影；手不得悬在产品旁边而无真实作用，不得穿入产品内部。
14. 手不得改变产品角度，不得遮挡产品核心识别区域（正面主体图案、壶口轮廓、壶口边缘厚度、壶内主要可见区域、配件连接关系）。
15. 手是辅助互动元素，不计入道具数量，但同样不得抢夺视觉中心。

道具与场景：
16. 道具数量克制，服务页面任务，不堆叠、不抢主体、不造成商品组成误解；具体数量与位置规则以《道具生成规则模块》为准。
17. 背景、前景、中景层次合理，但不得为了层次堆无效元素；不得把画面塞满。
18. 整体克制留白，避免大面积氛围滤镜、过度磨皮、过度高级化。
19. 非产品元素轻微真实瑕疵感只作用于产品本身以外的背景、道具、桌面、布料、纸张、食物、手部和环境光影；可保留桌面细微纹理、布料自然褶皱、纸张轻微翘边、食物自然不规整、手部自然皮肤纹理、真实接触阴影和轻微光影变化，但不得脏乱、廉价杂乱或抢主体。

禁止的典型 AI 痕迹：
20. 不得出现产品改形、边缘融化、材质发糊、光线平均发平、虚化机械、漂浮悬空、手部畸形、文字漂浮、道具穿模、液体僵平、阴影不贴地、整体看起来像 AI 样图而不是真实电商商品摄影。
21. 不得为了真实感重新设计产品；不得为了氛围改变产品角度；不得为了道具摆放牺牲产品主体地位；不得为了卖点展示补出绑定角度中不可见的结构。
22. 不得为了真实感让产品本身变脏、变旧、破损、开裂、掉色、图案磨损或出现原图不存在的瑕疵；不得把非产品元素轻微真实瑕疵感误用到产品身份上。
23. 不得让产品与手部或道具比例明显失真；产品占画面比例只代表构图，不代表实物尺寸改变。
```

## qc_runtime_summary_source

```text
九、质量底线精简摘要（可选，用于 ChatGPT 出图后质检）

本节用于在 ChatGPT 聊天窗口中对最终图片进行快速质检和返修判断；它只表达质量底线，不引入新的生成方向。

【质量底线精简摘要】

下列任何一条不满足，即视为不合格，需返回对应源文件修正，不得在本摘要中临时新增与源文件冲突的新要求：

产品身份底线：
1. 产品结构、比例、颜色、材质、纹理、图案、壶口、壶口边缘、壶身、壶壁、壶底或底足、壶柄/提梁/壶盖/出水口/滤网等配件空间关系必须与《产品身份档案》一致。
2. 不得出现产品改形、改色、图案丢失、配件消失、材质错误或结构变形。
补充：壶口厚度、壶口边缘转折、壶壁厚薄、壶底或底足支撑、壶柄或提梁连接点、壶盖/出水口/滤网/密封圈等配件关系、壶内液面和材质表现必须真实，且不得为了真实感、风格或道具重新设计壶型、添加壶柄或提梁、删除壶盖、改变壶口比例或改变壶身图案。
补充：不得因为非产品微瑕疵规则导致产品本身被做旧、加污渍、加划痕、加裂纹、改色、改材质、改结构、改图案或增加原图不存在的瑕疵。
补充：产品颜色必须以本张绑定白底产品图为准；套装各单件颜色必须以对应单件白底图为准。若生成图商品本体相较白底图出现整体偏黄、偏蓝、偏绿、偏灰、偏红、饱和度明显漂移、图案颜色错误或材质本色错误，判定为不合格。

产品角度底线：
3. 产品角度必须符合本张绑定白底产品图；产品朝向、俯仰关系、壶口可见程度、壶身外壁与壶底或底足透视关系、壶体与配件的空间关系不得被擅自改变。
4. 不得为了页面任务、风格或道具改变产品角度。

页面任务底线：
5. 主图须服务点击、识别、第一印象；详情图须服务信息解释、质感、结构、使用场景、比例关系或品牌氛围；不得把主图做成复杂详情页，也不得把详情图做成无信息任务的纯氛围图。
6. 套装图须清楚展示套装组成、件数、主次和相对比例，不得擅自增减或误导用户。
输出画布比例补充：主图输出画布必须为 1:1；详情图输出画布必须为 3:4，可采用 1440x1920。不得为了满足画布比例而裁掉产品关键识别区域、改变产品角度、改变产品真实尺寸关系或破坏页面任务。

真实感与构图底线：
7. 主光方向明确，明暗层次自然；产品与桌面、托盘、道具之间必须有真实接触阴影；不得出现漂浮、悬空、贴片感、阴影方向混乱、过亮反光、过度柔化或假氛围光。
8. 除非本张变量配置明确要求信息分区，否则不得出现拼图、宫格、多画面分栏、信息图面板或多个不连续场景。
9. 不得出现产品变形、边缘融化、材质发糊、手部畸形、文字漂浮、虚假景深、道具穿模、液体异常、比例错乱、接触关系失真等明显 AI 痕迹。

道具与文字底线：
10. 道具须服务页面任务、数量克制、服从风格母版和真实生活逻辑，不得遮挡主体、抢夺视觉中心或造成商品组成误解。
11. 文字须清晰可读、无乱码错字、不漂浮、不遮挡主体、不宣称当前角度无法支持的结构、材质、容量或使用价值。

手持与套装底线：
12. 若画面中出现手部，手部须真实、放松、有真实抓握逻辑；手不得改变产品角度，不得遮挡产品核心识别区域，包括壶口轮廓、壶口边缘、壶身器型、外壁图案、壶内主要可见区域和配件关系，不得抢夺视觉中心。
13. 套装件数、各单件数量、主次、相对比例、固定搭配、编排关系、可分性和道具边界不得被改变；套装组成单件不得被弱化、虚化或移出画面。

尺寸比例底线：
14. 产品与手部、道具、桌面参照物、配件、套装单件的大小关系必须符合《产品身份档案》或《套装产品身份档案》的真实尺寸字段；产品占画面比例只代表构图，不代表实物尺寸改变；尺寸未知或低置信度时不得启用手持或强比例参照道具，文字不得宣称未确认的尺寸、容量、重量、口径或比例关系。

风格保真底线（仅在本张声明高风格贴合或风格复现型时适用）：
15. 若参考图为丰富生活场景，生成图不得退化为纯色背景、单产品孤立、无前 / 中 / 后景层次；参考图无文字时不得擅自添加大标题；参考图含壶内饮品、奶泡或拉花且本张为生活化饮用场景时不得无内容物；风格贴合锚点命中明显不足即视为“风格一致性问题”。该底线只约束非产品视觉风格，不得借此改变产品身份、产品角度、尺寸比例，也不得复制参考图的具体品牌、文案和产品图案。

本摘要不引入新的生成方向，仅作为最终出图阶段的质量底线和返修判断标准。质检时只判断图片是否合格，不在本摘要中加入新的画面要求。
```
